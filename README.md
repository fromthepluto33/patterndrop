# 🌀 Pattern Drop

Онлайн-редактор для создания **бесшовных паттернов** прямо в браузере.
Собирайте узоры из изображений и векторных фигур, настраивайте раскладку —
и скачивайте результат в PNG, JPEG, WEBP или SVG.

## Возможности

- **Слои** — изображения (с диска или перетаскиванием) и фигуры (круг, квадрат,
  треугольник, стрелка, линия). Дублирование, скрытие, переупорядочивание
  перетаскиванием, смена цвета через палитру
- **Настройка мотива** — масштаб, поворот, прозрачность, отражение по
  горизонтали/вертикали
- **Раскладка** — «Обычная сетка» и «Кирпичная кладка», отступы между мотивами,
  точное смещение по осям X/Y
- **Мультивыбор** — выделение нескольких слоёв (Ctrl/Cmd+клик, чекбоксы),
  групповое перемещение и выравнивание
- **Холст на всё окно** — бесшовный узор заполняет весь экран; панели плавающие
  и перетаскиваемые, кнопка-«глаз» скрывает интерфейс
- **Экспорт** — PNG, JPEG, WEBP, SVG с настраиваемым размером (1–2000 px) и
  качеством; SVG доступен для полностью векторных композиций
- **Горячие клавиши** — полный набор (Delete, стрелки, Ctrl+Z/Y, Ctrl+D, Ctrl+G
  и другие), справочник по кнопке «?» в шапке
- **Темы** — светлая и тёмная с сохранением выбора

## Всё локально, ничего не отправляется

Приложение целиком работает в браузере на canvas: загрузка файлов, рендер и
экспорт выполняются локально. Никаких серверов, аккаунтов и отправки данных.
